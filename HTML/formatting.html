HTML Formatting Tags

<b> makes text bold.

<strong> shows important text.

<i> makes text italic.

<em> emphasizes text.

<u> underlines text.

<mark> highlights text.

<small> makes text smaller.

<del> shows deleted text.

<ins> shows inserted text.

H2O uses the <sub> tag.

E = mc2 uses the <sup> tag.
